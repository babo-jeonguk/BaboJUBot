# 홈 레퍼런스 조사: 여러 연구 조직을 한눈에 보는 첫 화면

조사일: 2026-10-27. 대상: 사용자 피드백 "홈의 디자인이 아쉽다, 레퍼런스 조사 후 결정". 구현 전 권고이며 채택한 결정은 [결정](#결정)에 적었다. 2026-10-28 사용자가 카드 홈 대신 에이전트 로비를 골랐다([결정 갱신](#결정-갱신-에이전트-로비-2026-10-28)).

## Brief

- 구현할 문제: 홈이 조직 수·실행 중 수 카드 두 개와 생애주기 단계별 가로 칸반이었다. 조직이 적으면 대부분의 칸이 빈 세로 띠가 되고, 사용자가 지금 봐야 할 조직(주의 필요)이 드러나지 않았다.
- 홈이 답할 질문: 어느 조직이 나를 기다리는가(주의 필요), 어느 조직이 지금 일하고 있는가(실행 중), 각 조직의 단계·목표·최근 활동, 새 조직 만들기.
- 고정된 조건: 설명 문장 없이 배치와 시각 상태로 말한다. 개발 정보(ID·API 이름)를 보이지 않는다. 1개·5개·30개 조직과 390px에서 모두 보기 좋아야 한다. 최종 완료·중단 조직이 진행 중 조직을 밀어내지 않는다. 주의 판정은 레일·Inbox와 같은 `needsAttention`이다.

### 결정 갱신: 에이전트 로비 (2026-10-28)

사용자가 시안을 보고 카드 홈(D01~D05)을 에이전트 로비로 바꿨다. 조직 하나가 방 하나이고, Lead는 왼쪽 큰 책상, 작업자는 들어온 순서로 정한 고정 자리(한 줄 여섯까지)에 앉으며 상태는 자리 대신 캐릭터의 모습으로 보인다. 위쪽 요약(D05)과 마지막 활동 시각(D06)은 그대로 쓴다. 사용자 결정:

1. 쉬는 에이전트는 방의 라운지 소파로 간다. 책상에는 이름표와 얼굴색 띠가 있는 빈 의자만 남는다.
2. 방은 상태 때문에 움직이지 않는다. 조직을 만든 순서(오래된 것이 먼저)로 놓아 새 조직은 맨 뒤에 붙고, 주의는 제자리에서(노란 띠·물음표 말풍선·주의 chip) 보인다. 최종 완료·중단 조직만 아래 접힌 `끝난 조직`으로 한 번 옮긴다(D02의 활동순·D01의 주의 구역을 대신함). Lead 포함 여섯 명까지는 반 폭, 일곱 명부터 전체 폭이며 더 많으면 줄을 늘려 아래로 자란다. 1440px 반 폭 방에 여섯 명이 한 줄로 들어가는 것을 홈 E2E가 확인한다.
3. 작업 중인 에이전트에 마우스를 올리거나 keyboard focus하면 머리 위 말풍선이 하는 일(맡은 작업 제목, 없으면 깨어난 이유)을 한 줄로 말한다. 늘 떠 있는 말풍선은 사용자 결정을 기다리는 Lead의 물음표뿐이다.
4. 로비가 기존 홈을 완전히 대신한다.

## 한계와 미확인

- Linear·Vercel·Devin·OpenAI Codex 화면은 로그인이 필요해 직접 조작하지 못했다. Linear는 공식 문서로, Vercel은 검색 결과 요약으로만(공식 페이지 본문은 404), Devin은 제3자 기록으로만 확인했다. Codex 웹 문서([learn.chatgpt.com/docs/cloud](https://learn.chatgpt.com/docs/cloud))에는 작업 목록 배치 설명이 없어 근거에서 뺐다.
- Paperclip·OpenClaw는 정적으로 읽었고 실행하지 않았다.
