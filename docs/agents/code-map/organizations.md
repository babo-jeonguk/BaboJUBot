## 연결 경로

공통 순서는 [공통 경로](shared-path.md)를 따릅니다.

```text
create-organization → api → POST /api/organizations(app)
  → harness loadHarnessLibrary·leadRoleOf → core planOrganizationCreation
  → db insertOrganizationCreation → EventHub → dispatcher.kick(Lead)
EventHub → WebSocket /api/events → live-events → live-refresh → 다른 탭 query 재조회
```

저장·알림 순서는 server/after-commit, Event 재연결 복구는 `useLiveEvents`에서 시작합니다.
