## 연결 경로

공통 순서는 [공통 경로](shared-path.md)를 따릅니다.

```text
대시보드·에이전트 상세 → POST /api/organizations/:id/{pause,resume,stop}·/agents/:agentId/{pause,resume}(app)
  → controlOrganization·controlAgent(조직 → 에이전트 → 진행 중 실행 시도 잠금, core plan*)
  → EventHub → dispatcher.cancel → finishRun(cancelled) → 재개면 kickOrganization·kick
Lead 대화(중단하고 보내기) → POST /messages {delivery: interrupt} → insertOwnerMessage
  → dispatcher.cancel → claimNextRun이 그 메시지 깨우기만 묶음(core bundleWakes) → 다음 실행 시도가 나머지를 묶음
줄 세운 메시지 → POST /messages/:messageId/{edit,withdraw,send-now}(app)
  → editQueuedMessage·withdrawQueuedMessage·sendQueuedMessageNow(core planEdit·planWithdrawal·planSendNow)
  → EventHub → (지금 보내기) dispatcher.cancel·kick
Lead 대화(실행 중단) → POST /agents/:agentId/interrupt → controlAgent → dispatcher.cancel
```

취소 뒤 늦은 도구 쓰기는 `lockRunningRun`의 `cancelReason`, 재개 뒤 실행이 없으면 `listAgentsWithPendingWakes`의 에이전트 `paused`·단계 필터에서 시작합니다.
