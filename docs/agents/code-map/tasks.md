## 연결 경로

공통 순서는 [공통 경로](shared-path.md)를 따릅니다.

```text
scripted(Lead) → /api/tools/tasks(server/tools) → toolWrite → db createTask(core planTaskCreation)
  → EventHub → dispatcher.kick(담당자) → claimNextRun → scripted(작업자)
      → /tasks/:id/start → /artifacts → /tasks/:id/complete(core planTaskCompletion)
      → 부모 담당자 또는 생성자 깨우기 → kick
작업 상세 댓글 → POST /api/organizations/:id/tasks/:taskId/comments(app) → insertOwnerTaskComment → kick(담당자)
```

깨우지 않은 할당·완료는 core/task.ts의 대상 선택, 다른 조직 참조는 db/tasks.ts의 확인과 복합 FK에서 시작합니다.
