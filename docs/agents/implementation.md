# 구현

이 저장소에서 `implement` 또는 구현을 요청하면 작업 브랜치 준비부터 구현·검증·로컬 리뷰·커밋·push·PR 생성까지 진행합니다.
별도 push·PR 생성 요청을 기다리지 않습니다. 사용자가 범위를 제한하거나 다른 전달 방식을 지정하면 그 지시를 따릅니다.
병합은 사용자의 병합 요청 후 [병합 절차](pr-merge.md)로 진행합니다.
공용 `implement` 스킬의 「현재 브랜치에 커밋」은 아래에서 확인한 작업 브랜치에 적용합니다.

## 1. 작업 위치와 근거 확정

- 시작 branch/worktree, 원격 base와 SHA, 미커밋 변경을 확인하고 기존 작업을 보존합니다.
  새 작업은 최신 원격 base에서 `feat/<이슈>-<주제>` 등 변경 성격에 맞는 브랜치를 만듭니다.
  같은 작업을 이어갈 때는 해당 브랜치·worktree를 재사용합니다. 기존 변경과 겹치면 별도 worktree로 분리합니다.
- 해당 이슈의 본문·댓글·parent·blocker와 [확정 기능](../features.md), 작업에 해당하는 AGENTS Routing 문서를 읽습니다.
  이슈가 없는 사용자 지정 작업은 대화에서 승인된 범위·완료 조건을 기준으로 삼습니다.
- `reference-first`의 기존 receipt·조사 문서를 출발점으로 삼고, 채택에 쓸 원문을 확인합니다.
  근거가 부족한 질문만 추가 조사하며, 권고와 확정 결정을 구분합니다.
- 미해결 제품 결정은 근거와 선택지를 사용자에게 전달하고, 그 결정과 독립적인 작업은 이어갑니다.

**완료 조건:** 기준 SHA·작업 브랜치·보존할 변경·요구사항과 열린 결정을 설명할 수 있습니다.

## 2. 구현과 검증

- 코드 지도에서 진입점·호출자·계약·검증 위치를 확인하고, 요구한 동작을 책임지는 경계에서 구현합니다.
  개발 중에는 관련 테스트와 타입 검사를 실행하고, 완료 시 변경 계약에 맞는 검증을 확보합니다.
- 검사 명령·환경은 [README의 개발 시작](../../README.md#개발-시작), 검증 범위와 SHA별 근거는
  [최종 head 검증](pr-merge.md#3-최종-head-검증)을 따릅니다.
  실패 출력과 종료 코드를 보존하며, 원인 확인 없이 재실행 성공만으로 실패를 해소하지 않습니다.
- 동작·계약·진입점이 바뀐 문서는 [문서 지도](../README.md)의 책임에 맞춰 같은 변경에서 갱신합니다.
  무관한 작업트리 파일에 의존하지 않도록 커밋 대상 파일만 있는 환경에서도 검증합니다.

**완료 조건:** 요구사항별 검증 근거와 미검증 범위가 있고, 구현·문서가 일치합니다.

## 3. 로컬 리뷰와 커밋

- 고정한 base와 작업 diff를 대상으로 `code-review`의 Standards·Spec 리뷰를 실행합니다.
  미커밋 파일도 검토 범위에 포함하고, 검토 대상과 이후 변경을 기록합니다.
- 지적 검증·수정과 재검토는 [리뷰 반영](review-fixes.md)을 따릅니다. 미해결 blocker를 해소한 뒤 진행합니다.
- 이번 작업의 파일·hunk만 stage하고 [커밋 규칙](commit-messages.md)에 따라 커밋합니다.
  hook이 파일을 바꾸거나 실패하면 변경과 원인을 확인한 뒤 필요한 검사를 다시 실행합니다.

**완료 조건:** 작업 범위만 담은 커밋이 있고, 로컬 리뷰 결과와 그 후 변경의 검증 근거가 연결됩니다.

## 4. Push·PR·외부 리뷰 인계

- 작업 브랜치를 push하고 base를 확인해 PR을 만듭니다. 같은 작업의 PR이 있으면 갱신합니다.
  본문에는 최종 범위·수정 전후 동작·검증 SHA와 결과·미검증 범위·병합 위험을 담습니다.
  연결 이슈를 실제로 완료하면 `Closes #N`을 쓰고, 부분 작업은 남은 범위를 명시합니다.
- PR의 필수 CI를 확인하고 실패를 해결합니다. 수정 commit이 생기면 본문과 검증 근거를 최신 head에 맞춥니다.
  CI가 제공하는 동일 코드의 근거를 활용하고, 환경 차이·새 실패·후속 변경이 있을 때 필요한 로컬 검사를 추가합니다.
- [외부 리뷰 요청 형식](review-fixes.md#외부-리뷰-요청-형식)으로 복사할 자료를 사용자에게 전달합니다.
  PR 생성은 외부 리뷰 통과나 병합 완료를 뜻하지 않습니다.

**완료 조건:** PR과 최종 head, 필수 CI 결과, 로컬 리뷰 처리, 외부 리뷰 요청 자료를 전달했습니다.
권한·환경 등으로 미완료인 항목은 실행한 작업과 분리해 정확한 blocker를 보고합니다.
