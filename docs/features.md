# 구현 기능 기준선

기준: 사용자 인터뷰와 최신 기능 확정 답변. 이 문서는 기능 범위이며 아래 기능은 아직 구현되지 않았습니다. 이슈별 상세 조사·결정·검증 항목은 GitHub 이슈에 기록합니다.

| 영역 | 확정 범위 | 아직 결정할 것 |
|---|---|---|
| 조직 | 연구 목표별 독립 조직, 전용 Lead와 팀, 조직별 상태 | 구체적인 데이터 형식·접근 제어 |
| 웹 대시보드 | 높은 우선순위. agent의 상태·담당 작업·관찰 가능한 활동·결과, 승인과 실행 제어, 연구 지도 | UI 프레임워크·세부 화면 |
| 초기 계획과 팀 | Lead 제안, 사용자 동시 승인 후 실행 | 반려·수정·승인 대상 버전 표현 |
| 구성원 | 사용자 승인 후 신규 작업자 추가, agent별 역할·성격·행동 원칙 | ROLE.md/SOUL.md 등의 형식·변경 권한 |
| 실행 | 작업 분해·분담, heartbeat, agent별 일시정지·재개, 조직 전체 중단·재개 | 실행 중 호출·외부 작업 처리와 재시도 정책 |
| 협력 | 같은 조직 작업자들의 직접 질문·결과 공유, Lead 조정 | 전달·대기·담당 변경 규칙 |
| 사용자 개입 | 진행 중 피드백과 새 작업, Lead의 우선순위 반영, 큰 목표 변경·추가 예산 시 사용자 판단 | 중요한 변경의 판단 기준 |
| Lead 채팅 | 목표 설정·질문·피드백·추가 작업을 대화로 수행 | 웹 CEO-style chat / Telegram / Slack / Discord 중 접점 선택 |
| 기본 연구 흐름 | 문제 식별·목록화 → 가설/아이디어 → 검증 방법 → 실험/검증 → 결과 평가·반복 | 관계 모델·단계별 상세 규칙 |
| 연구 지도·템플릿 | 트리 또는 마인드맵으로 기록·탐색, 다른 연구 철학의 템플릿 지원 | 엄격한 트리 / 교차 연결 지원, 템플릿 스키마 |
| 기억 | 조직 공통 목표·개발/연구 흐름·지식과 agent별 기억 구분, 조직 간 격리와 사용자 지정 공유 | 기법·저장·검색·회수. 해당 조사 이슈에서 결정하며 이번 init에서는 조사하지 않음 |
| 예산·시간 | 정책 설정, 사용량 추적, 한도에 따른 실행 제어 | 비용 정의·집계·동시 예약·초과 대응 |
| 보고·산출물 | 주요 진행·문제·결정 및 사용자 요청 시 보고, 연구별 산출물, Top-Down/MECE 보고서 | 품질·근거 검증 상세 방식. 다음 행동 제안은 선택 |
| 완료 | 목표 설정 시 완료 기준 합의, 결과 제출 후 사용자 검토로 최종 완료 | 수정 요청·재개·기준 변경 처리 |
| Agent용 조직 도구/API | 실제 Lead/worker가 작업·협력·기억·연구 기록·산출물·승인 요청을 호출, 실행 맥락 구성 | 최초 도구 노출 방식·capability·맥락 선택/크기 |
| 연구 역할·skills | 목표/계획·조사·가설·검증·검토·종합의 지침·입출력·필요 도구·검증 계약, 조직별 조합 | 첫 역할 구성·skill 형식·적용 방식 |
| 결과 검토·연구 반복 | agent가 근거를 평가하고 가설 수정·후속 검증·재계획·결과 제출을 판단, 선택과 근거를 기록 | template별 반복·진전 없음 처리·평가 분담 |

## 환경과 연구 하네스의 구분

- `orchestration`: AI organization의 조직·실행·협력·기억 접근·사용자 interaction 환경. 조직 경계·승인·예산·실행 제어를 제품에서 강제합니다.
- `research-harness`: Lead와 작업자의 자율 연구를 지원하는 역할·skills·절차·근거·실험·평가·보고 도구. 연구 전략과 다음 행동의 판단은 agent가 담당하며 다른 연구 철학의 템플릿을 적용할 수 있습니다.

## 범위 원칙

- 특정 게임·대회·모델·GPU는 활용 예시이며 공통 엔진의 전제 조건이 아닙니다.
- 웹 관찰 대시보드의 우선순위와 Lead 채팅 채널 선택은 별개입니다.
- GitHub blocker는 기능 구현의 선행 조건입니다. 이슈의 자료 조사와 설계 검토는 선행 구현 완료 전에 수행할 수 있습니다.
- 역할 문서나 agent 프롬프트만으로 승인·조직 경계를 강제했다고 판단하지 않습니다.
